# C3.5b comments donor baseline

Captured from the read-only AISL donor at
`81c6c1e4d95ed51d09368a41b99e64841ddfb43a` on 2026-09-05.

The donor `comments` app contains:

- 2,348 Python lines across models, services, thread lifecycle, API, migration and tests;
- one `0001_initial.py` migration;
- 73 test methods in seven files;
- `Comment` and its top-level `CommentVote`, both keyed to an opaque thread UUID;
- stable routes named `comments_endpoint`, `comments_reply` and `comments_vote`.

The reusable schema already avoids direct foreign keys to content owners, but permission dispatch
still imports plans and book-club code at request time. C3.5b will replace that dispatch with an
explicit target registry, keep public-read/authenticated-write as the default, and let registered
owners supply read/write checks and cascade deletion.

Comment-created notifications will emit through the C3.5a notification source boundary. AISL name
display, account activation, content-author resolution and site template composition remain site
adapters or overrides.
