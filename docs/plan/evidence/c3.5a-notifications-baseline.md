# C3.5a notifications donor baseline

Captured from the read-only AISL donor at
`81c6c1e4d95ed51d09368a41b99e64841ddfb43a` on 2026-09-05.

The donor `notifications` app contains:

- 6,908 Python lines across models, services, views, template tags, migrations and tests;
- 13 migrations from `0001_initial.py` through `0013_alter_notification_notification_type.py`;
- 234 test methods in 14 regular test files;
- one user-owned `Notification` model plus an event-specific `EventReminderLog` that imports the
  donor `events` app directly.

C3.5a will keep the `notifications` Django label and a provisional initial migration. The portable
model owns recipient, text, URL, kind, source identity, read state and timestamps. Event reminders,
Slack announcement delivery, plan/book-club/content lookups and donor tier selection stay behind
registered sources or remain site-owned.

The package will preserve the donor route names `notification_list`, `api_notification_list`,
`api_unread_count`, `api_mark_read` and `api_mark_all_read`. Package tests will verify recipient
ownership directly instead of copying donor page text or site-specific notification kinds.
