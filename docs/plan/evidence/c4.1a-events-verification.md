# C4.1a events models and domain services verification

Verified: 2026-09-05

## Delivered capability

- `Event`, `EventSeries`, `Host`, ordered `EventHost` and protected `EventAlias` models.
- Separate database, public and route-alias identities for events.
- Transaction-safe monotonic public-ID allocation with explicit reservation for imported IDs.
- Configurable host-profile resolution without a site import.
- Package access-policy checks for registration eligibility.
- Atomic publish, reschedule and cancellation transitions with after-commit signals.
- Weekly occurrence generation that preserves local wall-clock time across daylight-saving changes.

The `events` app keeps the donor label. Its initial migration is provisional and remains untagged.
