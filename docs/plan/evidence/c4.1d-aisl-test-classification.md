Classification meanings:

- Adapted: package tests exercise the shared behavior through package-owned models or surfaces.
- Boundary: the package owns a smaller portable contract; AISL keeps presentation, provider or
  product-specific policy.
- Site-owned: the behavior depends on AISL product models, navigation, analytics or visual design.
- C4.3: the assertion is historical migration or donor-schema evidence.
