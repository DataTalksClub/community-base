Captured from the donor repositories on 2026-09-05.

## Adapted into the package

- AISL `accounts/models/user.py`: email-first manager, shared user fields and bounce choices.
- AISL `accounts/models/email_alias.py`: alias ownership and uniqueness.
- AISL `accounts/models/email_change_request.py`: pending request state and uniqueness.
- AISL `accounts/models/privacy.py`: minimal privacy audit state and active-request constraint.
- AISL `accounts/models/import_batch.py`: import audit state and counters.
- DTC spec 01 member profile version 1: private one-to-one profile, stable choices, bounded text,
  safe links, completion version and optimistic revision fields.

AISL `accounts/tests/test_models.py` is intentionally empty under its testing policy. Package tests
therefore exercise the shared invariants directly rather than claiming copied donor test count.

## Site-owned and excluded

- AISL payment tier, pending tier, billing, Stripe customer and subscription fields.
- AISL `TierOverride`; ownership moves to payments.
- AISL legacy token and member API key models; ownership moves to the shared API app.
- DTC course learner fields and certificate name; ownership stays with `courses.LearnerProfile`.
- DTC identity reconciliation fields and records; ownership stays with `accounts_ext`.
- AISL user-save imports of payments and account credential services; those cross-app side effects
  are replaced by package services and signals in C3.1c.
