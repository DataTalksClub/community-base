{% comment %} Default markup for one annotated code block (community-base issue #255). A site owns its public design system (decision D18), so this template ships only structural hooks and no colour, spacing or typography: `annotated-code-block`, `code-line-gutter`, `code-line-number`, `code-annotation-line` with the `is-highlighted` modifier and a `data-line-number` attribute, `code-annotations`, `code-annotations-heading`, `code-annotation-list`, `code-annotation-note`, `code-annotation-label` and `code-annotation-text`. A site styles those hooks in its own stylesheet, and may override this file at the same path to emit different markup entirely. The gutter sits outside `` so a reader copies the source without the line numbers. Line text and note text are the only author-supplied strings here and both are autoescaped. {% endcomment %}
